# EditorNewsApp

An Android news reader application.

## Project Structure
- `app/`: Main application module containing Android source files, resources, and Gradle build configurations.
- `gradle/`: Gradle wrapper files.
- `build.gradle.kts` & `settings.gradle.kts`: Root Gradle build configuration files.

## Getting Started
To get started with the project, open it in Android Studio.

### Prerequisites
- Android Studio Ladybug or newer
- JDK 17+
- Android SDK 34+
